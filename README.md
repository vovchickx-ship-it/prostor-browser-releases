# Простор

Браузер для Windows 10 (1809+) и Windows 11, x64.

## Установка

Скачайте **Prostor-Setup-1.0.0.exe** в [последнем выпуске](https://github.com/vovchickx-ship-it/prostor-browser-releases/releases/latest) и запустите установщик.

Установщик создаёт ярлык и проверяет наличие Microsoft Edge WebView2. При отсутствии этого компонента потребуется интернет для его загрузки.

## Обновления

Браузер автоматически проверяет опубликованные версии. Когда обновление загружено, появляется окно с кнопкой «Обновить». Проверку также можно запустить в настройках, в разделе «О браузере».

Перед установкой проверяются цифровая подпись манифеста и контрольная сумма установщика. Вкладки, настройки и профиль сохраняются при обновлении.
